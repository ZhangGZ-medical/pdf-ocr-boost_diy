# OCR 质量评估与降级策略

## 置信度阈值与行动

| manifest 平均置信度 | 判定 | 行动 |
|---|---|---|
| ≥0.95 | 优 | 直接使用，抽检即可 |
| 0.85-0.95 | 良 | 使用，但数字/特殊符号需人工复核 |
| 0.75-0.85 | 中 | 可用但需坐标重建 + 下游人工修正（词条提取实测 0.73/0.87 均在此区间） |
| <0.75 | 差 | 提 DPI 到 400 重跑；仍差则换 Paddle 引擎 |

## 常见质量问题与对策

| 症状 | 对策 |
|---|---|
| 双栏错乱/中缝压成乱行 | rebuild_columns.py 坐标重建（勿依赖 pipeline 版面输出） |
| 英文首字母拆行（"a"+"ngiotensin"） | y_tol 勿 <30；正则 `^([a-zA-Z])\s+(?=[a-z])` 拼接 |
| 行尾断词（"qualita- tive"） | `(\w+)-\s+(\w+)` 合并 |
| 数字/罗马数字误识（1→l、Ⅸ→区、Ⅺa→"哑"） | 下游人工核对清单；不擅自改写 |
| 页眉检索字母串混入正文 | y<8% 或密集汉字+无英文的行剔除（pipeline 已剥离，重建时再过滤） |
| 对比度低的扫描件 | pipeline 的 CLAHE+二值化双通道已内置；仍失败提 DPI 400 |
| 空页/空结果 | pipeline 自动二值化回退；仍空则该页确无内容 |

## 降级决策树

```
OCR 置信度 < 0.85 ?
├─ 是 → 版面是否规整(词典/大字)?
│        ├─ 是 → 坐标重建 + 下游人工规则(成本低, 3-5% 行需人工)
│        └─ 否 → DPI 400 重跑 → 仍差 → Paddle 引擎(仅关键页)
└─ 否 → 直接使用
关键页(合同/数据页) → DeepSeek-OCR 精读(每页 20-90s, 语义级版面理解)
```

## 交付规范（与下游技能对齐）

- 所有计数/数字类断言必须给出检索清单供人工核验
- OCR 噪声词条原样保留并标注"待人工核对"，不擅自改写
- 交付说明中列明：提取范围、引擎、置信度、修正项（如 Thl→Th1）、待核对清单
