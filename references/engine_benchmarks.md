# 本机 OCR 引擎实测基准与选型矩阵（i5-1340P 纯 CPU，2026-08 实测）

## 实测数据

| 任务 | 引擎 | 页数 | 平均置信度 | 耗时 | 结果质量 |
|---|---|---|---|---|---|
| 《常用临床医学名词》目录.pdf（双栏、大字） | RapidOCR | 3 | 0.730 | 40.8 秒 | 第 1 页双栏错乱（坐标重建修复）；第 2/3 页可用 |
| 临床检验专业名词.pdf（双栏词典） | RapidOCR | 5 | 0.870 | 348 秒（每页约 70 秒） | 词条级提取 459 条，错误率约 3-5%（人工规则修正） |

## 引擎选择矩阵

| 场景 | 推荐引擎 | 理由 |
|---|---|---|
| 词典/名词表/规整大字版面 | **RapidOCR** | 0.87 置信度足够词条提取；速度快 20-40 倍 |
| 表格/复杂版面/低清扫描 | **PaddleOCR Server** | 0.98+ 置信度；表格网格识别强 |
| 少量高价值页（合同/关键页）、版面语义要求高 | **DeepSeek-OCR** | VLM 直接理解版面（表格/公式/阅读顺序），每页 20-90 秒 |
| 批量初扫/草稿浏览 | RapidOCR | 最快，先扫后精 |
| 混合场景 | RapidOCR 全量 → 置信度 <0.85 的页用 Paddle 重跑 | 成本最优 |

## 速度-精度权衡的经验值

- RapidOCR 置信度 0.73 → 目录型版面够用，但**页码数字噪声多**（`: 212`、`· 385`），数字类内容需人工复核
- RapidOCR 置信度 0.87 → 词条正文可用，噪声集中在：中缝区、页眉检索串、特殊符号（Ⅸ→"区"、1→l）
- Paddle Server 置信度 0.988 → 基本免复核，但**单页 23 分钟**（该页为复杂表格切片），批量不可行
- DeepSeek-OCR 修复前不可用（依赖缺失 + transformers 版本冲突）；修复后理论每页 20-90 秒
